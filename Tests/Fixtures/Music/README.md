# Fila 音乐编辑测试样本

这是三段现场合成的原创测试音频，只包含简单的正弦音序列，没有引用或采样现有歌曲。可自由用于导入、播放及音乐元数据编辑测试。

| 文件 | 时长 | 曲号 | 声音特征 |
| --- | --- | --- | --- |
| 01-Ascending.m4a | 6 秒 | 1/3 | 上行音序 |
| 02-Alternating.m4a | 8 秒 | 2/3 | 交替音序 |
| 03-Slow-Pulse.m4a | 10 秒 | 3/3 | 慢速低音 |

三个文件都是 AAC-LC / M4A、44.1 kHz、单声道，音量保守，头尾和音符间带平滑包络。每个文件均包含标题、歌手、专辑歌手、专辑、年份（2026）、曲号、碟号（1/1）、流派、作曲者和注释。完整标签、时长与 SHA-256 校验值见 Validation.json 和 SHA256SUMS.txt，已由 ffprobe 逐项验证。

## 导入后再测试

1. 使用系统音乐应用所支持的导入、同步流程，把这些音频导入目标设备的音乐资料库。仅将文件复制到设备上的普通文件夹，不会自动建立系统音乐资料库条目。
2. 在目标设备的系统音乐应用中确认三首歌可见、可播放，再打开 Fila 的音乐列表并刷新。
3. 记录原始标签后，分别验证 Fila 开放编辑的标题、年份、曲号、碟号和注释。一次只改一个字段，保存后刷新并对照系统音乐应用读取的结果。
4. 如 Fila 报告保存失败，保留错误信息及对应曲名；不要使用直接 SQL 写入代替原生保存。

## 边界

本目录只有可导入的音频和说明，不包含、读取或导出任何真实用户音乐资料库。请勿将任何文件覆盖到 MediaLibrary.sqlitedb，也不要替换其 WAL/SHM 文件。
