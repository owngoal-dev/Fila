Fila 0.6.2 lets you swipe through a folder's images, puts favourites one tap away on the breadcrumb, and keeps favourites inside the bootstrap working after you jailbreak again.

- An image opened from a folder now swipes left and right through the other images in that folder, in the order the list shows them. A zoomed image pans to its edge before the swipe moves on, and the title, breadcrumb and file menu follow the image on screen.
- Tap the current folder's name in the breadcrumb, marked with a star, to add it to or remove it from Favorites and to jump to any favourite. Hold it to jump to one of the Places.
- roothide and rootless move their bootstrap to a new folder each time you jailbreak. Favourites inside it now move with it, so they open the same folder instead of one that is gone. Fila starts following the bootstrap the first time 0.6.2 connects, so favourites left in a bootstrap removed before that are not recovered.

Choose the RootHide or the rootless Debian package for a jailbroken device, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
