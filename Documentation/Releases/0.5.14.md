Fila 0.5.14 counts what a folder holds, searches every folder below the one you start in, and takes a deleted row away the moment you ask.

- Properties on a folder adds up everything inside it: the size, the space on disk and the number of items, shown as they grow — "1.2 GB (Counting…)" — until the count is done. Links are not followed, a file with several names is counted once, and folders that could not be read are named under the totals. The folder's own entry size, which said nothing about its contents, is gone.
- Search goes all the way down. It used to stop eight folders deep and after 100 matches, and to pass over any folder too large to list at once; now it reads every folder below the starting one, page by page, up to 10,000 matches. Symbolic links are still not followed. The Find Files shortcut stops as soon as it has as many results as it asked for.
- A deleted or put-back item leaves the list as soon as you tap. A swipe no longer closes back over the row and the context menu no longer flies back into it; a listing read while the delete was running can no longer put the row back afterwards; and if the delete fails, the row returns.
- A card with three or more choices lists them first, highlighted, with Cancel last in the plain style. Copy Here or Move Here on a drop, and the share list for an SMB server, had Cancel on top — the share list had it highlighted.

Choose the RootHide or the rootless Debian package for a jailbroken device, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
