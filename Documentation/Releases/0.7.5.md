Fila 0.7.5 is a smaller download.

- The RootHide package was 24.2 MB, 3.4 MB of it six large copies of the app icon. The icon now ships as three compressed images, and the package is 20.8 MB. The icon looks the same on the Home Screen in Default, Dark, Clear and Tinted; it no longer moves with the light the way the layered glass icon did.

Choose the RootHide or the rootless Debian package for a device running custom firmware, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
