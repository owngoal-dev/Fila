Fila 0.8.1 fixes what was in the way.

- Applications and Music can be left again: Back, the edge swipe and the breadcrumb work there. On a phone the Places bookmark is back, so the full list of places is one tap away.
- A file shared to Fila from the Files app is copied, not moved. The original stays where it was.
- Compressing a folder no longer fails on some system languages.
- Open With appears only for files it can hand over; a folder no longer answers "Invalid argument".
- A long press on a row offers Select, and a folder's menu is shorter: its actions come first, View and Hidden Files are switches that update while the menu stays open, and New moved next to Go.
- The tab overview's plus opens a new tab on a tap and lists places on a long press. Closing every tab is a red trash.
- A read-only volume is a badge on its icon, not words after its name.
- Properties wraps a long path instead of cutting it to one line, and the licences page shows a licence under each name without version numbers.

Choose the RootHide or the rootless Debian package for a device running custom firmware, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
