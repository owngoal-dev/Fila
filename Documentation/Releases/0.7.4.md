Fila 0.7.4 prepares a data folder of its own when it is installed.

- Installing the Debian package now creates `Documents/wiki.qaq.fila` for mobile — and `Documents` itself where the bootstrap had none — so Fila has a folder no other app writes into, as a sandboxed app would. Nothing else changes.

Choose the RootHide or the rootless Debian package for a device running custom firmware, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
