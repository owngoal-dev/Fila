Fila 0.8.2 clears up the small print.

- The line under the last row is three buttons now, underlined and against the trailing margin: the count opens the folder's properties, and the free space or the read-only mark opens a page about the filesystem — where it is mounted, what it is formatted as, who owns it, and how much is used and free. The mount point on that page is a way there.
- A file with no extension has a document icon instead of an empty tile.
- The clipboard says "Copy 3 items" and nothing else; a row is the name and where it came from, without the third line of type and size.
- Go to Path is in the breadcrumb's menu and under the tab overview's plus, and a long press on the title asks for it too. A folder's menu no longer repeats Go on a phone, and no longer carries the file's name as its title.
- The row that says how the folder is shown now names the layout it is in — "Show as List" while it is a list — and switches to the other one when tapped.
- Nothing is drawn above the first row of a list any more.
- The places menu has no heading, and closing every tab is still the red trash.
