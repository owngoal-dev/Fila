Fila 0.5.13 reads its rows as whole sentences with VoiceOver, names the controls that showed only a value, and speaks the state that was only drawn.

- A file row, a sidebar row, a search result, a grid tile, a song and a line in the hex viewer are each one stop now, read as one sentence: the name, then what the second line and the size column say. Each used to be two or three separate stops, and the hex line spoke its column padding and pipes.
- The Properties button on a row is now reached through the actions rotor, since the row itself is one target. That is also the only way to it under Switch Control.
- A symbolic link says that it is one. A link wears its target's icon, so a link to a picture used to read exactly like the picture.
- A picked tile in the grid is announced as selected. The fill behind it was the only thing that said so.
- The Format, Compression and Encryption rows in Compress, and Open at Launch in General Settings, now name the setting and speak the choice. Only the chosen value was read before, and in General Settings the chosen folder was lost behind the setting's name. The Guest switch on an SMB share takes its row's title, and the image viewer names the picture after its file.
- In Progress and Recent in Transfers are headings, so the rotor can jump between them.
- Decorative artwork, the corner badges and the two spinners are skipped rather than stopped on.
- A build check now refuses a label VoiceOver would never reach, which is how the browser's rows had been unreadable since they were written.
