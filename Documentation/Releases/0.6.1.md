Fila 0.6.1 builds again with Xcode 27. Nothing changes in how the app behaves.

- Archives are read and written through libarchive.xcframework 1.0.0, whose Swift module is named ArchiveKit. The old name, LibArchive, differed from the C library's only by case, and on a case-insensitive disk Xcode 27 refused to load it. The module alias that worked around that is gone. The libarchive binary is the same one 0.6.0 shipped, so every archive format behaves as before.

Choose the RootHide or the rootless Debian package for a jailbroken device, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
