Fila 0.6.4 opens Word, Excel, PowerPoint, Pages, Numbers, Keynote and RTF documents.

- Tap a `.doc`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.pages`, `.numbers`, `.key` or `.rtf` file to read it as a page, including files only root can read. A workbook shows a tab for each sheet, and a presentation shows its slides one after another. Templates, slideshows and macro-enabled files open too.
- A document is shown the way iOS draws it, with no copy saved anywhere and nothing loaded from the internet. Tapping a web link in a document opens it in Safari.
- A file the system cannot draw, such as a damaged `.docx`, opens in the viewer for what it contains: the archive browser, hex or text. Open As › Document switches back to the page view.
- RTF files now open formatted. Open As › Text still edits them.

Choose the RootHide or the rootless Debian package for a jailbroken device, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
