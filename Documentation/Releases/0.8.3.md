Fila 0.8.3 is made for iPhone Duo.

- Fila is built against the iOS 27.1 SDK. On iPhone Duo Search, Tabs and More run down the side under the status bar, and the path bar takes the width they leave; on the inner display the places sidebar sits beside the folder.
- Buttons that show only an icon carry their names, so a menu that gathers buttons the bar has no room for lists them by name.
- Shared files, operation covers and app artwork are drawn at the scale of the display they are on, not the main screen's.

Choose the RootHide or the rootless Debian package for a device running custom firmware, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
