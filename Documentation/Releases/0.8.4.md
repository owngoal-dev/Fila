Fila 0.8.4 reads better in Chinese.

- The Simplified and Traditional Chinese translations read more naturally and use the same words as the system.
- When a shortcut cannot get root access, it now asks for a device running custom firmware rather than a jailbroken one.

Choose the RootHide or the rootless Debian package for a device running custom firmware, the TrollStore TIPA for TrollStore, or the standard IPA to sideload. SHA-256 checksums are in `SHA256SUMS`.
